# Light-element core

Density of a liquid iron core with H, C, N, O, Si and S: the linear law, calibrated on the outer cores of Hirose et al. (2021) for S, Si, O and H and taken from Li et al. (2019) Table 3.3 for C, and the Fe-H-O member of Luo et al. (2024). The [mixing page](../../Explanations/mixing.md#light-element-core) describes the model.
